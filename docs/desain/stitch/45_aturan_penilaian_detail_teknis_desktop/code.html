45 Aturan Penilaian

Dokumentasi matematis struktur pengambilan keputusan berbasis penalaran logika hierarkis dalam menetapkan status kewaspadaan kebakaran hutan dan lahan.

Ringkasnya
Kekeringan dan cuaca api dinilai terpisah dulu, lalu digabung jadi satu skor.

Pendekatan hierarki dua tingkat ini menyederhanakan kombinasi variabel cuaca yang kompleks menjadi keputusan yang transparan dan dapat dilacak. Setiap parameter diproses secara independen guna mencegah bias interaksi sebelum agregasi final.

Catatan Efisiensi Model: Tanpa bertingkat butuh 243 aturan (3 × 3 × 3 × 3 × 3). Dengan model berjenjang, sistem hanya membutuhkan total 45 aturan. Hal ini meminimalkan kombinatorial ledakan aturan tanpa mengorbankan akurasi klasifikasi lapangan.

Prinsip Penilaian Bahaya

Setiap kondisi diberi skor bahaya 0 (aman), 1 (sedang), atau 2 (berbahaya). Jumlah skor menentukan hasil aturan.

Skor 0
Kondisi Aman

Kelembapan tinggi / curah hujan meredam rambatan api.

Skor 1
Kondisi Sedang

Kondisi transisi dengan ambang batas bahaya termal menengah.

Skor 2
Kondisi Berbahaya

Kekeringan parah atau hembusan angin kencang berisiko tinggi.

Tentang Situs

Sistem Peringatan Dini Karhutla Kaltim dikembangkan untuk pemantauan potensi kebakaran hutan dan lahan berbasis estimasi cuaca terpadu di wilayah Kalimantan Timur.

Sumber Data

Prakiraan cuaca harian dari Open-Meteo. Hasil sistem diuji dengan data titik panas NASA FIRMS 2019 sampai 2026.

Penting

Skor menunjukkan potensi bahaya berdasarkan cuaca, bukan kepastian kebakaran. Untuk keadaan darurat, hubungi BPBD setempat.
