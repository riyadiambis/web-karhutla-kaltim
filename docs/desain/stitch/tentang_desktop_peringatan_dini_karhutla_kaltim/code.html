Keterbatasan Operasional

air Hanya parameter cuaca

Sistem hanya membaca cuaca (kelembaban udara, suhu, curah hujan akumulatif, dan angin), bukan memantau aktivitas korek api, pembukaan lahan, atau sumber pemantik manusia langsung.

grid_goldenratio Resolusi spasial 28 km

Satu kotak model mewakili area sekitar 28 × 28 km (0,25 derajat grid cuaca numerik). Variasi vegetasi mikro atau rawa gambut lokal di dalam petak memerlukan observasi darat.

cloud_sync Rentang prakiraan > 3 hari

Prakiraan 4 hari ke depan atau lebih masih kasar karena dinamika awan konvektif tropis Kalimantan yang bergerak dinamis. Selalu utamakan pantauan hari berjalan (H0) dan esok (H+1).

Tentang Situs

Sistem Peringatan Dini Karhutla Kaltim dikembangkan untuk pemantauan potensi kebakaran hutan dan lahan berbasis estimasi cuaca terpadu di wilayah Kalimantan Timur.

Sumber Data

Prakiraan cuaca harian dari Open-Meteo. Hasil sistem diuji dengan data titik panas NASA FIRMS 2019 sampai 2026.

Penting

Skor menunjukkan potensi bahaya berdasarkan cuaca, bukan kepastian kebakaran. Untuk keadaan darurat, hubungi BPBD setempat.
