Hasil Uji dengan Data Satelit

Evaluasi kemampuan model membedakan hari berapi menggunakan 57.105 titik panas NASA FIRMS periode 2019 sampai 2026.

Ringkasnya

Sistem paling baik membedakan hari berapi dibanding dua cara sederhana. Diuji dengan 57.105 titik panas VIIRS NASA FIRMS di Kalimantan Timur, 2019 sampai 2026.

Kemampuan membedakan hari berapi (AUC)

Nilai 1 berarti sempurna, 0,5 sama dengan menebak.

Metrik ROC-AUC

Fuzzy paling baik membedakan hari yang ada api dari hari yang tidak ada api.

AUC harian dan korelasi Spearman bulanan tiga metode. Sumber: notebook bagian F2.

Kurva ROC

Perbandingan sensitivitas dan rasio alarm palsu.

Hampir di sepanjang kurva, garis fuzzy berada di atas dua cara lain: lebih banyak api tertangkap untuk jumlah alarm palsu yang sama.

Alarm vs kenyataan

Ambang alarm didefinisikan saat sistem mengeluarkan status bahaya Tinggi dan Sangat Tinggi (skor ≥ 50).

572.460 Hari-Grid

Alarm (kelas Tinggi dan Sangat Tinggi) menangkap sebagian besar hari berapi, dengan harga alarm palsu yang cukup banyak.

Jumlah hari-grid 2019 sampai 2026. Sumber: notebook bagian H2.

Musim kebakaran 2026, hari demi hari

Kronologi skor bahaya harian disandingkan dengan lonjakan titik panas satelit FIRMS (Juli sampai September 2026).

Skor risiko bertahan di atas batas kelas Tinggi sejak awal Agustus, sebelum titik panas memuncak pada 19 Agustus.

Titik panas di tiap kelas risiko

Frekuensi harian deteksi titik panas NASA FIRMS pada setiap kelas risiko model cuaca.

Makin tinggi kelas risiko, makin sering titik panas muncul.

Persentase hari-grid yang memuat minimal satu titik panas. Sumber: notebook bagian E6.

Porsi hari vs porsi titik panas

Kelas Tinggi dan Sangat Tinggi hanya sebagian kecil hari, tetapi menampung sebagian besar titik panas.

Sumber: notebook bagian H3.

Stabil dari tahun ke tahun

Fuzzy unggul di setiap tahun, baik tahun kering maupun tahun basah.

AUC per tahun (2019 sampai 2026). Sumber: notebook bagian H5.

Memilih ambang alarm

Ambang rendah menangkap lebih banyak api tetapi lebih sering salah alarm. Ambang 50 dipilih karena api yang terlewat lebih merugikan daripada alarm palsu.

Presisi, recall, dan F1 untuk ambang skor 25 sampai 75. Sumber: notebook bagian H4.

Hari paling aman vs paling berisiko 2026

Saat hampir semua kotak hijau, tidak ada titik panas. Saat kotak merah mendominasi, titik panas bermunculan.

Rincian Angka dan Artinya

Hari-grid
Satu titik grid pada satu hari. Itulah satuan yang dihitung.
AUC: fuzzy 0,802, if-else tegas 0,748, hari tanpa hujan saja 0,701
Ukuran seberapa baik cara hitung membedakan hari berapi dari hari tanpa api. Model fuzzy paling tinggi dan unggul konsisten di 8 dari 8 tahun evaluasi.
Korelasi Spearman bulanan 0,666
Seberapa selaras naik-turunnya skor risiko dengan naik-turunnya jumlah titik panas dari bulan ke bulan. Makin dekat ke 1, makin selaras.
Status alarm
Gabungan kelas Tinggi dan Sangat Tinggi. Alarm muncul pada 19,2% hari-grid, tetapi berhasil mencakup 60,94% hari-grid berapi dan 72,9% titik panas.
Presisi 10,55%
Dari semua alarm, sekitar 11 dari 100 benar-benar diikuti titik panas. Sisanya alarm yang tidak berujung api, karena sistem hanya menilai cuaca.
Lift 3,17 kali lipat
Peluang titik panas pada hari alarm 3,17 kali lipat peluang dasar (3,32% hari-grid memuat titik panas).

Keterbatasan

  • Sistem hanya menilai cuaca. Sumber api (misalnya pembakaran lahan oleh manusia), jenis lahan, dan gambut belum diperhitungkan.
  • Data cuaca berupa rata-rata area sekitar 28 km, sehingga lebih halus dibanding pengukuran stasiun.
  • Karena pemicu api tidak dinilai, banyak alarm tidak diikuti kebakaran (presisi masih rendah).
  • Prakiraan H+4 ke atas lebih mudah meleset.

Skor adalah potensi bahaya berdasarkan cuaca, bukan kepastian kebakaran.

TENTANG SITUS

Sistem Peringatan Dini Karhutla Kaltim dikembangkan untuk pemantauan potensi kebakaran hutan dan lahan berbasis estimasi cuaca terpadu di wilayah Kalimantan Timur.

SUMBER DATA

Prakiraan cuaca harian dari Open-Meteo. Hasil sistem diuji dengan data titik panas NASA FIRMS 2019 sampai 2026.

PENTING

Skor menunjukkan potensi bahaya berdasarkan cuaca, bukan kepastian kebakaran. Untuk keadaan darurat, hubungi BPBD setempat.
