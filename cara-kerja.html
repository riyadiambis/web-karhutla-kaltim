Skala Indeks Bahaya (0 sampai 100)

Tingkat kerentanan yang dikonversi menjadi panduan tindakan pencegahan di lapangan.

0 25 50 75 100
Rendah 0 sampai 25

Lahan lembap, risiko penyebaran api sangat kecil bahkan jika ada pemicu.

Sedang 25 sampai 50

Permukaan mulai kering. Api bisa merambat pelan di vegetasi terbuka.

Tinggi 50 sampai 75

Serasah kering mudah tersulut. Api menyebar cepat jika terbantu angin.

Sangat Tinggi 75 sampai 100

Kekeringan parah. Potensi kebakaran hebat yang tak terkendali.

TENTANG SITUS

Sistem Peringatan Dini Karhutla Kaltim dikembangkan untuk pemantauan potensi kebakaran hutan dan lahan berbasis estimasi cuaca terpadu di wilayah Kalimantan Timur.

SUMBER DATA

Prakiraan cuaca harian dari Open-Meteo. Hasil sistem diuji dengan data titik panas NASA FIRMS 2019 sampai 2026.

PENTING

Skor menunjukkan potensi bahaya berdasarkan cuaca, bukan kepastian kebakaran. Untuk keadaan darurat, hubungi BPBD setempat.
